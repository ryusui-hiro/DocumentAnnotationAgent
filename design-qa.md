## Design changes and comparison

The concept makes Agent progress and human review the workbench's first-order elements. The implementation keeps all four Agent modes visible above execution settings, along with current work, next action, page coverage, review count, and candidate decisions. Assist applies clear low- and medium-priority results and holds high-priority or uncertain results for a person. Autopilot applies every clear result, reports high-priority items, and waits only on uncertain evidence. Each candidate exposes add, edit, and reject actions; the page link and canvas now align to the active review candidate, including after restoring a saved pending workspace.

The export control now opens an explicit click menu with native output first, rather than resembling a hover-only menu while immediately downloading JSON. Document badges and units distinguish PDF pages, Word pages, PowerPoint slides, and Excel sheets. Key labels and controls are larger, advanced configuration is collapsed, and the in-app help includes the generated four-format workflow visual.

Excel now uses a readable worksheet grid with a sheet picker, a visible 16-column window, navigation across the first 80 preview columns, and a stated row/column preview limit. Change cards jump to visible target cells. Pending, approved, and rejected changes can load original values beside proposed values, including targets outside the grid. Large ranges page through bounded 5 × 8 slices; a small 5 × 8 target is kept wholly inside its context window. Context columns use Excel letters when the actual header row is unknown.

## Findings and verification

Earlier review identified buried review controls, an ambiguous export menu, unclear document format, small labels, a mismatch between the pending candidate page and the canvas, and undisclosed Excel preview limits. Those issues are resolved in the current screenshots and UI. Final UI review found no remaining actionable P0–P2 issues at 390, 1280, or 1440px.


The production-preview browser E2E verifies PDF approve, correction, rejection, and JSON export, then reloads persisted run history, exports its event and human-decision record, and confirms a same-named PDF with a different source hash cannot see the old history or annotations. It keeps the cooling-fan PDF as the default and also opens the optional fictional termination-contract demo; the browser confirms the PDF contains no preset answer labels, the persistent notice identifies the scripted content as not AI-run and not legal advice, and reviewing the candidate does not hide that notice or call an AI endpoint. It then selects the image alone, confirms it renders, queues and resolves a mocked visual review candidate, and exports the folder-relative annotation record.
